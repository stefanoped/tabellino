# Tabellino Auxilium

Web app per registrare le statistiche live delle partite di basket (pensata per tablet in orizzontale).

- Funziona offline una volta installata (Chrome → menu ⋮ → *Installa app*).
- I dati restano solo sul dispositivo (memoria del browser): nessun dato viene inviato online.
- Dalla scheda **Partite**: nuova partita, archivio, esporta/importa backup (.json).
